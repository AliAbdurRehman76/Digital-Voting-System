# 🗳️ C++ Election Management System

## 📌 Project Description
This is a **console-based Election Management System** developed in **C++** as part of my **2nd Semester project**.  
It simulates both **General Elections** and **Local Body Elections**, providing a real-world inspired voting and result management system.  

This project was developed under the guidance of my respected Lab Engineer **Sir Abdullah Hamid**. 🙌  

---

## 🚀 Features
- ✅ **Voter Eligibility Check** – validates age & ballot number before allowing voting  
- ✅ **General Elections** – voting for **National Assembly** & **Provincial Assembly** seats  
- ✅ **Local Body Elections** – includes **Mayor**, **Village Councillor**, **Youth Councillor**, and **Minority Councillor** seats  
- ✅ **Secure Access** – election results can only be accessed with a **secret PIN**  
- ✅ **Vote Counting System** – displays candidate-wise results in a **tabular format**
